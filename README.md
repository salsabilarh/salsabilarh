## 📌 Proyek Pilihan

### [Forum API — Arsitektur Clean & 100% Test Coverage](https://github.com/salsabilarh/forum-api-dicoding)
> Produk akhir *Backend Developer Expert* — skor sempurna 5/5.

- **4 layer Clean Architecture** (Domains, Applications, Interfaces, Infrastructures) dengan dependency injection — setiap use case independen dari framework.
- **100% test coverage** (53 test files) — unit, integrasi, fungsional; otomatis via GitHub Actions CI/CD.
- **Optimasi N+1 query** pada komentar/like — dari O(n) ke O(1) roundtrip database.
- **JWT dual-token auth + RBAC** + soft-delete pattern.

`Node.js` `Hapi.js` `PostgreSQL` `Jest` `Docker` `NGINX` `Clean Architecture`

### [OpenMusic API — Async Decoupling & Caching](https://github.com/salsabilarh/openmusic-api-dicoding)
> Submission *Fundamental Backend JavaScript* — skor sempurna 5/5.

- **Redis cache layer** (30 menit TTL) untuk endpoint playlist — kurangi beban PostgreSQL.
- **RabbitMQ async pipeline** untuk ekspor email — non-blocking request handling.
- **Normalized 10-table schema** dengan migration versioning, mendukung kolaborasi playlist dan audit log.

`Node.js` `Hapi.js` `PostgreSQL` `Redis` `RabbitMQ` `JWT`

### [Bookshelf App — Frontend Murni Tanpa Framework](https://github.com/salsabilarh/bookshelf-app-dicoding)
> Submission *Front-End Web untuk Pemula* — skor 4/5.

- **CRUD + live search + modal edit** dengan DOM manipulation murni.
- **Persistent storage** via `localStorage` + load healing untuk data korup.
- **XSS protection** dengan `escapeHtml()` — bukti kesadaran keamanan.

`JavaScript` `DOM API` `localStorage` `HTML5` `CSS3`
